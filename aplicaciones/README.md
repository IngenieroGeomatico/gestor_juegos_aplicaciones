# Aplicaciones

Cada aplicación vive en su propia carpeta. Mismo patrón que en `juegos/`:

```
aplicaciones/<app>/
├── data/          # datos de la app en JSON
├── scripts/       # utilidades Python (ejecutar con `uv run ...`)
└── README.md
```

## Aplicaciones disponibles

De momento ninguna. Los scripts de muestra de ejemplo serían: para aplicaciones
de pago, extraer la parte de pago para usar la app sin restricciones; o cualquier
otra tarea de automatización/manipulación.
